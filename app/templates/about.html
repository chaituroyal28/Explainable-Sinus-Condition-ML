ABOUT THE PROJECT

Making survey-based ML explainable.

SinusPredict AI is an academic machine-learning project that explores whether demographic, symptom, allergy, environmental and treatment-related survey responses can be used to model a self-reported sinus-condition outcome.

01. PURPOSE

What is SinusPredict AI?

The project demonstrates an end-to-end supervised machine-learning workflow using structured survey data. The application combines prediction, model evaluation and explainability in a single interactive interface.

ML

Machine Learning

Six classification models were evaluated using the cleaned Sinus Survey dataset, followed by model comparison and hyperparameter tuning.

XAI

Explainable AI

SHAP and permutation importance are used to provide model-level and prediction-level information about feature influence.

DA

Data Analysis

The project includes dataset cleaning, exploratory analysis, statistical testing, cross-validation and held-out evaluation.

UI

Interactive Application

SinusPredict AI presents the academic workflow through a responsive Flask-based web interface.

05. LIVE MODEL

Tuned Decision Tree

The model currently used by the application

The web application uses the tuned Decision Tree selected from the evaluated models based on its highest held-out test-set F1 score in this experiment. The model achieved an F1 score of 56.90% and ROC-AUC of 53.68% on the 200-record held-out test set.

06. EXPLAINABILITY

Why explanations matter

A prediction alone does not describe how a machine-learning model arrived at an output. SinusPredict AI therefore includes explainability methods alongside prediction.

S

SHAP

SHAP values provide attribution information for transformed features and show whether individual contributions support the model's Yes or No class.

P

Permutation Importance

Permutation importance provides a model-level view by measuring how performance changes when feature values are shuffled.

08. LIMITATIONS

Important context

Self-reported data

The target represents a self-reported survey outcome rather than an independently verified clinical diagnosis.

Dataset size

The cleaned dataset contains 1,000 records, which limits how broadly the experimental findings can be generalized.

Limited performance

The held-out test-set performance is limited, so the model should be interpreted as an academic prediction experiment.

No causal interpretation

Feature importance and SHAP values describe model behavior and do not establish causal relationships.

Academic & medical disclaimer

SinusPredict AI is an academic machine-learning project based on self-reported survey data. Its outputs are predictions from a trained model, not medical diagnoses, and should not replace professional medical advice or evaluation.
