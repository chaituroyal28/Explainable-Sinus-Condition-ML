TECHNICAL & ACADEMIC RESEARCH

From Survey Data to Explainable ML

SinusPredict AI is an academic machine-learning project that investigates whether demographic, symptom, allergy, environmental and treatment-related survey responses can be used to model a self-reported sinus-condition outcome.

01. RESEARCH QUESTION

What does this project investigate?

The project evaluates whether supervised machine learning can identify patterns in a cleaned self-reported Sinus Survey dataset and predict the survey's reported diagnosis outcome.

Project framing

The target variable is Diagnosed with Sinus Condition . This is a self-reported survey outcome and is therefore treated as a machine-learning target, not as a medically verified diagnosis.

02. DATASET

The Sinus Survey

The original dataset contained 1,006 records and 11 columns. Six duplicate rows were removed before modeling, producing the cleaned dataset used in analysis.

Dataset size

1,006 original records → 1,000 cleaned records.

Input variables

10 predictor variables were used to model the self-reported diagnosis target.

Age range

Survey respondents range from 18 to 65 years.

Missing values

No missing values remained after the dataset cleaning stage.

03. INPUT FEATURES

What information enters the model?

Demographic

Age and Gender.

Sinus history

Regular Sinus Issues and Sinus Severity (1–5).

Environmental factors

Most Problematic Season and Triggered by External Factors.

Allergy & treatment

Known Allergy, Doctor Consulted, Headaches / Facial Pain and Medication Frequency.

05. EXPERIMENT DESIGN

Training and evaluation

Stratified split

The cleaned dataset was divided into 800 training records and 200 held-out test records using stratification.

Cross-validation

Five-fold stratified cross-validation was used during model evaluation and hyperparameter tuning.

Hyperparameter tuning

Randomized search was used to explore model configurations using F1 score as the tuning metric.

Held-out evaluation

Final model performance was measured on the 200-record test set that was not used for model fitting.

08. EXPLAINABLE AI

Understanding model behavior

Explainability was included so that the system does not only return a prediction, but also provides information about which transformed features influenced model behavior.

SHAP

SHAP values are used to attribute the model's prediction to individual transformed features. Positive values support the model's Yes class, while negative values support the No class.

Permutation importance

Permutation importance measures how model performance changes when a feature's values are shuffled. It provides a model-level importance view rather than a causal effect.

In the project's permutation-importance analysis, Age had the largest mean importance, followed by Medication Frequency. In the SHAP summary, Age had the largest mean absolute SHAP value among the transformed features. These results describe model behavior and are not evidence that these variables cause sinus conditions.

10. RELATED WORK

Previous research

Existing research demonstrates that machine learning has been explored for sinus-related analysis using medical imaging and other data sources.

RELATED LITERATURE · 2024

Machine Learning-Based Approach For Sinus Detection In Medical Imaging

Karthikeyan D., Parthasarathi B., Parthasarathi R., Senthilkumar S., Sudhahar D.

The paper describes a machine-learning approach for sinusitis detection using facial images and image-classification techniques. Its proposed approach discusses deep-learning/CNN-based image analysis and classification between sinusitis cases and healthy states.

The related work also discusses research using CT scans, including a study based on 57 CT scans for detection of nasal cavities and paranasal sinuses, and another comprehensive sinus-disease dataset containing annotated CT-scan samples.

These studies provide context for the use of machine learning in sinus-related research, but their imaging-based problem setting differs from the survey-based tabular prediction problem addressed by SinusPredict AI.

11. RESEARCH POSITIONING

Related work vs. this project

Related imaging research

  • Medical images such as CT or facial images are used as input.
  • Image-processing and deep-learning approaches are discussed.
  • CNN-based classification is part of the proposed approach.
  • The research is oriented toward medical-image analysis.

SinusPredict AI

  • Uses a structured self-reported survey dataset.
  • Uses demographic, symptom, allergy, environmental and treatment-related variables.
  • Evaluates six traditional and gradient-boosting classifiers.
  • Uses SHAP and permutation importance for explainability.
12. LIMITATIONS

Important limitations

  • The dataset contains self-reported survey responses rather than independently verified clinical diagnoses.
  • The dataset contains 1,000 cleaned records, which limits how broadly the results can be generalized.
  • The held-out test-set performance is limited, with the tuned Decision Tree obtaining an F1 score of 56.90% and ROC-AUC of 53.68%.
  • The model captures statistical patterns in the available survey data and does not establish causal relationships.
  • Model performance may change on a different population or a newly collected dataset.
  • The application should not be used as a substitute for professional medical evaluation.
13. CONCLUSION

What this project demonstrates

SinusPredict AI demonstrates an end-to-end machine-learning workflow for a survey-based sinus-condition prediction task. The project combines data cleaning, preprocessing, classification, cross-validation, hyperparameter tuning, model comparison, statistical analysis and explainability.

Among the six evaluated models, the tuned Decision Tree produced the highest held-out test-set F1 score in this experiment. The web application then exposes that model through an interactive survey interface and provides prediction-level explanations.

The central contribution is therefore an explainable academic ML workflow rather than a clinical diagnostic system.
